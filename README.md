# AI Security - Face Recognition System

AI-powered face recognition security and attendance system built with Python.

## Features

- Admin login and authentication
- Create new user account
- Face registration and recognition
- Attendance management
- Unknown-face detection
- Security incident logging
- AES-256-GCM encrypted storage
- Encrypted face data
- Security event logging
- Unknown-face snapshots
- Liveness / anti-spoofing checks
- User profile management
- Duplicate attendance prevention
- Premium security-focused desktop interface

## Security

Sensitive runtime data is excluded from GitHub.

Protected local data:
- `secure_data/`
- `*.key`
- `users.txt`
- `face_model.yml`
- `venv/`
- `__pycache__/`

## Requirements

- Windows
- Python 3.11
- Webcam
- Git
